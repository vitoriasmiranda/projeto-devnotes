# DevNotes

DevNotes é um aplicativo simples e intuitivo para você organizar suas anotações. Permite criar, fixar, buscar, editar, duplicar e exportar notas, garantindo que suas ideias e lembretes estejam sempre acessíveis.

---

## Funcionalidades

* **Criar Notas:** Adicione rapidamente novas anotações.
* **Fixar Notas:** Marque notas importantes para que elas apareçam sempre no topo.
* **Editar Notas:** Modifique o conteúdo das suas notas a qualquer momento.
* **Buscar Notas:** Encontre facilmente notas específicas usando a barra de pesquisa.
* **Duplicar Notas:** Crie cópias de notas existentes com um clique.
* **Excluir Notas:** Remova notas que não são mais necessárias.
* **Exportar CSV:** Baixe todas as suas notas em um arquivo CSV para backup ou uso externo.
* **Persistência de Dados:** Suas notas são salvas localmente no navegador (usando `localStorage`), então elas permanecem mesmo após fechar e reabrir o navegador.
* **Responsivo:** Design adaptável para diferentes tamanhos de tela (embora focado no desktop).

---

## Tecnologias Utilizadas

* **HTML5:** Estrutura da página.
* **CSS3:** Estilização e layout da interface.
* **JavaScript (Vanilla JS):** Lógica principal do aplicativo, manipulação do DOM e gerenciamento do `localStorage`.
* **Bootstrap Icons:** Para os ícones visuais (pesquisar, adicionar, fixar, excluir, duplicar, baixar).
